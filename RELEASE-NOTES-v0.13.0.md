# BaskovAndroid v0.13.0 — Shared Playlists

- Adds a new Home entry for shared server playlists.
- Create a playlist on Android and immediately see/use the same playlist through Discord `/playlist`.
- Open playlist details, play the whole list on the phone, rename, delete, reorder and remove tracks.
- Search Baskov remote tracks directly inside the playlist editor and add one selected result.
- Owner permissions are enforced by the backend using the paired Discord identity; other users' playlists are read-only on Android.
- Shared playlists contain remote provider-backed tracks for now. Phone-local files will join only after the future local-track-to-Discord transport exists.
