# BaskovAndroid v0.14.1 — Favorites UX & Scale

- Favorites paginate instead of being product-capped at 100 tracks.
- Now Playing uses a compact `♡` / `♥` toggle with repeat-tap removal.
- Remote search results expose the same favorite state.
- MediaSession publishes a favorite custom action for Android system media controls where the system/OEM surfaces it.
- Favorite membership is addressed by stable logical track key rather than mutable list position.
